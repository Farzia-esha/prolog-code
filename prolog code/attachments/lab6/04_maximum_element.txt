Problem 4: Maximum Element in a List

Prolog Solution
----------------

max_list([X], X).

max_list([H|T], Max) :-
    max_list(T, TailMax),
    max_two(H, TailMax, Max).

max_two(A, B, A) :-
    A >= B.

max_two(A, B, B) :-
    A < B.

Sample Query
------------
?- max_list([4,9,2,15,7], M).

Expected Output
---------------
M = 15.
