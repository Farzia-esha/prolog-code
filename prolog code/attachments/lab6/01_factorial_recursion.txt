Problem 1: Factorial Calculation (Recursion)

Prolog Solution
----------------

% Base case: factorial of 0 is 1.
factorial(0, 1).

% Recursive case.
factorial(N, F) :-
    N > 0,
    N1 is N - 1,
    factorial(N1, F1),
    F is N * F1.

Sample Query
------------
?- factorial(5, F).

Expected Output
---------------
F = 120.
