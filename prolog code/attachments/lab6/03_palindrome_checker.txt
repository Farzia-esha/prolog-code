Problem 3: Palindrome Checker

Prolog Solution
----------------

palindrome(List) :-
    reverse_list(List, Reversed),
    List = Reversed.

% Recursive reverse predicate used by palindrome/1.
reverse_list([], []).

reverse_list([H|T], Output) :-
    reverse_list(T, Rest),
    append_one(Rest, H, Output).

append_one([], X, [X]).
append_one([H|T], X, [H|R]) :-
    append_one(T, X, R).

Sample Query
------------
?- palindrome([r,a,c,e,c,a,r]).

Expected Output
---------------
true.

Another Query
-------------
?- palindrome([1,2,3,4]).

Expected Output
---------------
false.
