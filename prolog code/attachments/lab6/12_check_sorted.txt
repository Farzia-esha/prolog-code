Problem 12: Check if a List is Sorted

The predicate succeeds only when the list is in ascending order.

Prolog Solution
----------------

% Empty and one-element lists are sorted.
sorted([]).
sorted([_]).

% Check each pair of consecutive elements.
sorted([A,B|T]) :-
    A =< B,
    sorted([B|T]).

Sample Queries
--------------
?- sorted([1,2,3,4,5]).

Expected Output
---------------
true.

?- sorted([1,3,2,4]).

Expected Output
---------------
false.
